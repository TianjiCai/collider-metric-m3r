# Shared Intraclass Scripts

This directory is for intraclass analyses that are not tied to a single metric.
Metric-specific results should still be written into the existing metric
folders, for example `metric_comparison/w2/intraclass_comp/output/`.

## Jaccard Progression

Run the full Jaccard progression for W2, PS, and SW:

```bash
python metric_comparison/intraclass_comp/intraclass_jaccard_anchors.py
```

Useful options:

- `--metrics w2 ps sw`: choose which metrics to process.
- `--classes qcd HToBB`: process a subset of jet classes.
- `--neighbors-step 100`: control the neighbor-count grid for Jaccard curves.
- `--no-plots`: write only summary CSVs.

The script writes:

- `metric_comparison/<metric>/intraclass_comp/output/jaccard/intraclass_jaccard_summary.csv`
- `metric_comparison/<metric>/intraclass_comp/output/jaccard/jaccard_aucs_summary.png`
- per-class histogram and Jaccard-curve PNGs in the same `output/jaccard/` folder.

The paper-facing combined plot is generated by:

```bash
python paper_plots/complexity_estimation/jaccard_aucs_all_metrics.py
```

This writes `jauc_all_metrics*.pdf` files.

## Decision-Ordering Progression

Run the full sampled progression for W2, PS, and SW:

```bash
python metric_comparison/intraclass_comp/intraclass_decision_ordering_anchors.py
```

Useful options:

- `--metrics w2 ps sw`: choose which metrics to process.
- `--classes qcd HToBB`: process a subset of jet classes.
- `--sample-pairs 20000 --sample-references 128`: control the sampled
  estimate of `decision_ordering_sim`.
- `--exact --num-jets 30`: call the exact utility function for small smoke
  tests.

The script writes:

- `metric_comparison/<metric>/intraclass_comp/output/decision_ordering/intraclass_decision_ordering_summary.csv`
- `metric_comparison/<metric>/intraclass_comp/output/decision_ordering/decision_ordering_summary.png`

The paper-facing combined plot is generated by:

```bash
python paper_plots/complexity_estimation/decision_ordering_progression_all_metrics.py
```

This writes `mado_all_metrics*.pdf` files. The normalized JAUC/MADO
metric-by-metric plots are generated by:

```bash
python paper_plots/complexity_estimation/jauc_mado_ratio_by_metric.py
```

This writes `jauc_mado_ratio_by_metric*.pdf`,
`jauc_mado_raw_by_metric*.pdf`, `jauc_ratio_all_metrics*.pdf`, and
`mado_ratio_all_metrics*.pdf`.

## MDS Gram-Matrix Euclideanity Diagnostics

Run the classical MDS Gram-matrix test for all available large JetClass labels
and all three metric types:

```bash
python metric_comparison/intraclass_comp/intraclass_mds_gram_diagnostics.py
```

Useful options:

- `--classes QCD HToBB` or `--classes 0 1`: process a subset of classes.
- `--sample-jets 1000`: randomly subsample each intraclass distance matrix for
  a fast exploratory PSD/effective-dimension check.
- `--save-eigenvalues`: save the full Gram spectrum for each processed matrix.
- `--no-plots`: write only CSV summaries.

The script writes:

- `metric_comparison/<metric>/intraclass_comp/output/mds_gram/intraclass_mds_gram_summary.csv`
- `metric_comparison/<metric>/intraclass_comp/output/mds_gram/mds_gram_summary.png`
- `metric_comparison/intraclass_comp/output/mds_gram/intraclass_mds_gram_summary_all_metrics.csv`

The key columns are `negative_eigenvalue_count`,
`is_euclidean_by_gram_psd`, `exact_embedding_dimension`,
`negative_frobenius_fraction`, and `dim_95`.
